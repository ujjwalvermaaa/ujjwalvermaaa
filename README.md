**What I built:**

- **Adware Automation System** — A production-grade browser automation framework using Python and Playwright that simulates real user journeys across brand websites. **End-to-end multi-agent GenAI studio that turns startup ideas into complete business plans, roadmaps, and investor documents.**

FoundrAI takes a raw startup idea and autonomously produces a complete business plan, product roadmap, competitive analysis, and investor-ready pitch deck. Built on **LangGraph** for multi-agent orchestration and **LangChain** for LLM interaction, with RAG pipelines grounding all outputs in real market data.

**Key Features:**
- Multi-agent pipeline using LangGraph — each agent handles a distinct business domain
- RAG pipeline grounds all outputs in real-world data using FAISS vector store
- Supports Qwen and Llama models via Ollama for fully local, private inference
- FastAPI backend with async streaming endpoints for real-time agent responses

**Tech Stack:** `Python` `FastAPI` `LangGraph` `LangChain` `RAG` `FAISS` `Qwen` `Llama` `Ollama`
